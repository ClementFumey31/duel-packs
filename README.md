# Duel Packs

Jeu de collection Yu-Gi-Oh! : ouvre des boosters (10 max, +1 toutes les 10 min) et complète tes extensions.
Application web installable (PWA), 100 % locale, sans compte.

- Cartes et extensions : YGOPRODeck (chargées à l'usage, puis en cache)
- Taux de drop par époque : voir `engine.js`
- Sauvegarde : localStorage (Profil > Exporter)

## Publication
Settings > Pages > Source : Deploy from a branch > `main` / `/ (root)`.

## Installer sur téléphone
- iPhone : Safari > Partager > Sur l'écran d'accueil
- Android : Chrome > menu > Installer l'application
